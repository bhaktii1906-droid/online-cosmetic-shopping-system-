💄 Online Cosmetic Shopping Management System

📌 Project Overview

The Online Cosmetic Shopping Management System is a web-based application designed to make cosmetic shopping easier and more convenient. Users can explore cosmetic products and view product information through an online platform.

This project aims to provide a simple shopping experience and organize cosmetic product information efficiently.

🎯 Objectives

- To provide an online platform for cosmetic shopping.
- To display cosmetic products and their details.
- To make product browsing convenient for users.
- To manage product information systematically.
- To provide a user-friendly interface.

✨ Features

- 🛍️ Browse cosmetic products
- 💄 View product information
- 🗂️ Organize cosmetic product details
- 🖥️ Simple and user-friendly interface
- 🗄️ Database support using MySQL

Add login, cart, order management, payment, or admin features here only if they are implemented in your project.

🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Development Environment: Visual Studio Code / XAMPP

⚙️ Installation and Setup

1. Install "XAMPP" (https://www.apachefriends.org/).

2. Clone or download this repository.

3. Copy the project folder into the XAMPP "htdocs" directory.

4. Start Apache and MySQL from the XAMPP Control Panel.

5. Open phpMyAdmin at "http://localhost/phpmyadmin".

6. Create the database and import the project's SQL file, if provided.

7. Update the database connection settings in the project to match your local MySQL configuration.

8. Open the application in your browser:
   
   "http://localhost/your-project-folder/"

Replace "your-project-folder" with the actual folder name.
